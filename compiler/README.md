# EasyS Compiler

Компилятор и CLI языка **EasyS**.

Полная документация, синтаксис и инструкции по запуску — в [корневом README](../README.md).

## Команды

```powershell
npm install
npm run build
npm test
npm link

easys init my-site
easys build examples/full.easys
easys build examples/easys-demo/src/App.easys
```

## Demo

```powershell
cd examples/easys-demo
easys check
easys build
easys dev
```
